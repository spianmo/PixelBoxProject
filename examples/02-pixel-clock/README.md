# 02 像素时钟

NTP 对时的大字号像素时钟,自带天气,触摸屏幕在三种表盘之间切换(选择会被记住):

1. **经典**:大数字 + 秒进度条 + 日期星期 + 天气
2. **极简**:纯时间,冒号每秒呼吸
3. **霓虹**:色相流动的彩色数字

## 演示的 API

| API | 用途 |
|---|---|
| `px.system.ntpSync()` / `setTimezone('CST-8')` | 联网对时(失败自动重试 3 次) |
| `px.system.now()` | Unix 毫秒,示例内手动换算 UTC+8,不依赖引擎时区 |
| `fetch('https://wttr.in/?format=%t|%C&lang=zh')` | 拉取天气,纯文本自定义格式流量极小,每 30 分钟刷新 |
| `px.input.onTouch` | 触摸切换表盘 |
| `px.storage.kv` | 持久化表盘选择 |

大数字不是内置字体,而是 **5x7 点阵 + fillRect 整数放大** 自绘的,想要多大就有多大,且永远是锐利的像素风。

## 运行前提

设备已配网(天气与 NTP 都需要网络)。离线时时钟仍会走(显示"对时中..."),天气显示留空。

## 可以动手改的地方

- `TZ_OFFSET_HOURS` 改成你的时区;
- 在 `GLYPHS` 里补上 `-`、`.` 等字符,把日期也换成大点阵;
- 把 wttr.in 换成任何返回 JSON 的天气 API(`res.json<T>()` 直接拿类型)。
