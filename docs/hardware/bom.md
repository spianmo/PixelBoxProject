## 决策建议

- 只想玩软件/验证产品:**停在 Stage A**,总投入 ¥300~500,当天可玩。
- 要摄像头/GPS/灯带或形态定制:走 Stage B,预算 ¥1500 左右、周期 1~2 个月(含两轮打样)。
- Stage B 动手前先确认 **#B-2-2 屏幕货源**——它决定项目成败,先拿到屏和 datasheet 再画板。
