# Stage B:定制 PCB 新手完整教程(立创 EDA 专业版 + 嘉立创)

> 目标读者:资深软件工程师,**从没画过板子**。本章带你走完:
> 建工程 → 模块化原理图 → 布局布线 → DRC → 嘉立创下单(含 SMT)→ 回板调试。
>
> ⚠️ 诚实声明(必读):
> 1. 本文给出的是**模块级设计方法、参考设计出处与常见坑**,不提供引脚级"照抄即可"的原理图——
>    每个模块都必须以对应芯片 datasheet 与所列开源参考设计为准自己画,这是硬件设计无法绕过的功课。
> 2. 所有价格均为**估算量级**,以嘉立创当日报价为准。
> 3. 第一版板子有错是常态(业内叫"respin"),预算和心态上按 2 版规划。

## 0. 心智模型:硬件流程 ≈ 你熟悉的软件流程

| 硬件 | 软件类比 |
|---|---|
| 原理图(Schematic) | 接口声明 / 依赖图:哪个引脚连哪个信号 |
| 器件封装(Footprint) | ABI:引脚的物理排布,错了直接"链接失败"(焊不上) |
| 布局布线(Layout) | 实现 + 性能优化:同样的逻辑,布得差就是跑不稳 |
| DRC(设计规则检查) | lint / 静态检查:线宽、间距、开孔合规性 |
| 打样 + SMT | CI + 部署:一轮 1~2 周,所以 review 要在下单前做足 |
| 回板调试(bring-up) | 集成测试:按依赖顺序逐模块点亮 |
| 参考设计(Reference Design) | 官方 SDK 示例代码:能抄就抄,别自己发明 |

**最重要的一条原则:每个模块都有官方参考设计,你的工作是"组合与检查",不是"发明"。**

## 2. 工程建立与组织

1. 立创 EDA 专业版 → 新建工程 → 命名 `pixelbox-v1`。
2. 原理图**按模块分多页**(Page),每页一个功能块,像拆代码模块一样拆:

```
Page1  电源:USB-C 输入 + AXP2101 + 各路电源轨
Page2  主控:ESP32-S3-WROOM-1-N16R8 最小系统
Page3  显示:AMOLED QSPI 接口 + FPC 排线座 + 触摸
Page4  音频:ES8311 + MEMS 麦 + 功放 + 喇叭座
Page5  外设:OV2640 DVP 座 + ATGM336H GPS + WS2812 + 按键 + 电池座
```

3. 页间用**网络标签(Net Label)**连接(如 `I2C_SDA`、`3V3`),等价于全局变量名——命名规范些,后面布线全靠它。
4. 搜器件优先选**"立创商城"库且有 C 编号、且标注"基础库"**的器件(基础库 SMT 免上料费,扩展库每种收几十元上料费,见 §7)。
5. 每放一个器件,**必须点开核对封装**(Footprint)与 datasheet 引脚图一致——封装错误是新手第一大翻车点,EDA 不会帮你查。

## 3. 模块化原理图:逐模块要点、参考出处与坑

### 3.0 先做引脚分配表(动笔前最重要的一步)

ESP32-S3 可用 GPIO 有限,外设又多,先在表格里分配完再画图:

- **不可用/慎用**:
  - GPIO26~32:被模组内 Flash 占用(WROOM-1 不引出);
  - **GPIO35/36/37:N16R8 的 Octal PSRAM 占用,绝对不能用**(新手最经典的坑,板画完才发现);
  - GPIO19/20:USB D-/D+,留给 USB;
  - **Strapping 引脚 GPIO0 / GPIO3 / GPIO45 / GPIO46**:决定启动模式,只能接按键/悬空/弱上下拉,
    不要接会在上电瞬间拉电平的外设(比如接了某芯片的输出脚 → 上电进错模式,现象是"随机变砖")。
- 数一数需求:QSPI 屏 ~6 脚、触摸 I2C 共享 +INT/RST、I2S 4 脚 + MCLK、I2C 2 脚、
  DVP 摄像头 **8 数据 + PCLK/VSYNC/HREF/XCLK + SCCB(可共享 I2C)≈ 12+ 脚**、GPS UART 2 脚、
  WS2812 1 脚、按键若干——**摄像头是吃脚大户,先分它**。
- 留 2~3 个备用 GPIO 引到测试点/排针,救命用。

> 引脚分配表建议直接放进仓库(如 docs/hardware/pinmap-v1.md),与固件 `boards/` 板型文件互为对照。
> 固件规则:引脚只出现在板型文件里,其他组件禁止硬编码(architecture.md §3)。

### 3.1 ESP32-S3-WROOM-1-N16R8 最小系统

- **选型**:用**模组**(WROOM-1-N16R8:16MB Flash + 8MB Octal PSRAM)而不是裸芯片——RF 部分模组已调好且过认证,新手用裸片必翻车。
- **参考设计**:乐鑫《ESP 硬件设计指南》"最小系统"一节 + ESP32-S3-DevKitC-1 开源原理图,**逐脚照抄**。
- 必备要素:
  - EN 脚复位电路:10kΩ 上拉 + 1µF 对地电容(RC 延时复位);
  - BOOT 按键:GPIO0 对地按键(+ 可选 RESET 按键:EN 对地);
  - 3.3V 去耦:模组电源脚就近 10µF + 0.1µF;
  - UART0(TXD0/RXD0)引出测试点或排针——USB 烧不进时的后门。
- **坑**:
  - **电源必须扛得住 Wi-Fi 发射峰值**:3.3V 轨按 **≥500mA 持续 / 瞬态更高** 设计,电源轨上放 ≥100µF 大电容;电压跌落的现象是"一开 Wi-Fi 就重启(brownout)"。
  - **天线净空区**:见 §5,布局阶段最重要的一条。
  - N16R8 的 PSRAM 是 Octal:sdkconfig 要匹配(固件已配好),硬件上记住 GPIO35~37 不可用即可。

### 3.2 AMOLED QSPI 接口 + FPC 排线座 + 触摸

- **参考设计**:微雪 ESP32-S3-Touch-AMOLED-1.8 原理图(wiki 下载)是最直接的参照——同款屏、同款驱动(SH8601)、同款触摸(FT3168)。
- 组成:QSPI 6 线(CS / CLK / D0~D3)+ 复位脚 + 触摸 I2C(+INT/RST)+ 屏电源。
- **屏的采购决定一切**:1.8" 368×448 SH8601 AMOLED 裸屏 + 对应 FPC 排线座,
  **必须先找到屏的 datasheet 再画接口**(淘宝搜"1.8寸 AMOLED SH8601"或询屏厂)。
  排线座的脚数/脚距/上接下接全由屏的 FPC 定义,**禁止照抄别家板子的座子型号**。
- **坑**:
  - FPC 座**上接/下接搞反 = 整排引脚镜像**,新手翻车率极高;把屏的 FPC 金手指面画在纸上比划一遍再定;
  - AMOLED 需要的电源轨按屏 datasheet:逻辑 1.8V/3.3V 之外,AVDD 或升压轨是否屏内自带 power IC,【以屏规格书为准】,微雪原理图会告诉你它是怎么解决的;
  - QSPI 走线:短(<50mm 量级)、同组等长(工程经验 ±5mm 内即可,不是 DDR 那种苛刻等长)、完整参考地平面;
  - 触摸 INT 脚别占用 strapping 引脚。

### 3.3 音频:ES8311 + MEMS 麦 + 功放

- **参考设计**:乐鑫 **ESP32-S3-BOX / ESP32-S3-Korvo-2** 开源原理图(官方音频板,ES8311 就是从这些板子来的标准搭配);ES8311 datasheet(Everest 顺芯)。
- 信号链:
  - 录:模拟 MEMS 麦(带偏置)→ ES8311 MIC 输入 → ADC → I2S → S3;
  - 放:S3 → I2S → ES8311 DAC 线路输出 → **模拟功放**(如 NS4150B 一类 3W 内 D 类,参考乐鑫板选型)→ 喇叭;
  - 控制:I2C(与触摸等共享总线,注意地址不冲突:查各芯片 7bit 地址列一张表);
  - 时钟:MCLK 由 S3 输出给 ES8311(数 MHz,走线短)。
- **坑**:
  - **麦克风布局远离喇叭与 DCDC**:麦挨着喇叭 = 回声/啸叫,挨着电感 = 底噪;麦开孔朝外、孔道短,周围留密封圈压环区(装配时用泡棉圈贴外壳);
  - D 类功放输出线是高频方波,**别与麦克风走线并行**,喇叭线短粗;
  - 功放电源就近 ≥10µF 退耦,否则大音量爆音/复位;
  - I2S 各线同层短走线即可(音频速率不高),但 MCLK 相对高频,注意别绕远路穿过 RF 区。

### 3.4 电源:AXP2101 + 锂电池

- **参考设计**:AXP2101 datasheet(X-Powers)+ 微雪原理图(它同样用 AXP2101,是最贴近的实例)。
- 组成:USB 5V 输入 → AXP2101(充电 + 电量计 + 多路 DCDC/LDO)→ 3.3V 主轨及外设轨;电池座(1.25mm,丝印标极性!);PWRON 按键(长按开关机)。
- **坑**:
  - **上电默认电压**:AXP2101 各路输出的开机默认值由芯片配置决定,必须核对默认值就能把 3.3V 主轨拉起来(否则芯片没上电就没人去写 I2C 改配置——鸡生蛋问题)。照抄微雪的接法可规避;
  - 电池 NTC 脚:不接温度探头时按 datasheet 要求处理(固定电阻),悬空可能拒绝充电;
  - 充电电流按电池容量设置(0.5C 以内);
  - DCDC 电感是噪声源:远离 RF 与音频,见 §5。

### 3.5 USB-C

- 作为受电设备(UFP):**CC1、CC2 各接一颗 5.1kΩ 下拉电阻**——漏了这两颗,用 C-to-C 线缆就不供电(A-to-C 线正常),这是 USB-C 板子最著名的坑。
- D+/D- 接 S3 的 GPIO20/GPIO19(原生 USB,烧录/JTAG/串口三合一)。
- VBUS 入口:ESD 保护管(如 USBLC6-2SC6 类)+ 防反灌;若 VBUS 直接进 AXP2101 则按其 datasheet。
- **坑**:D+/D- 是 90Ω 差分对,布线要求见 §5;USB-C 座子选**贴片+插板混合脚**的型号(纯贴片座容易被拔线扯飞)。

### 3.6 OV2640 摄像头(DVP)

- **参考设计**:乐鑫 **ESP32-S3-EYE** 开源原理图 + esp32-camera 组件文档(它列出了 DVP 接法与推荐引脚)。
- 组成:24pin 0.5mm FPC 座(市售 OV2640 模组的事实标准,仍需【核对】所购模组 datasheet)、
  8bit 数据 D0~D7 + PCLK/VSYNC/HREF + XCLK(S3 输出 ~20MHz)+ SCCB(I2C 协议兼容,可共享总线)+ 电源。
- **坑**:
  - 电源:OV2640 裸片需 2.8V/1.2V 双轨,但**常见排线模组已内置稳压**只需单轨供电——买模组时看清,决定你要不要多两路 LDO;
  - XCLK 20MHz 走线短、远离麦克风与 RF;
  - PCLK 上串 22Ω 电阻位(留着,信号过冲时救命);
  - 引脚多,和 §3.0 的分配表反复对——摄像头几乎决定整板引脚方案。

### 3.7 ATGM336H GPS

- **参考设计**:中科微 ATGM336H datasheet(官网可下,含参考电路)。
- 组成:UART(默认 9600bps NMEA)接 S3 任一 UART;天线二选一:
  板载陶瓷贴片天线(净空要求高)或 **IPEX 座 + 外接有源天线**(推荐,室内表现好得多);
  VBAT 备份电源(小纽扣电池或超级电容,可选)加速热启动。
- **坑**:
  - 有源天线要**馈电**:天线口经电感向天线馈 3.3V,照 datasheet 参考电路抄;
  - GPS 天线离 Wi-Fi 天线越远越好(对角布置),且远离 DCDC;
  - **室内定位不到是正常现象**,调试去窗边/室外,首次冷启动定位需 30 秒以上;
  - PPS 脚可引出 LED,搜星成功秒闪,调试直观。

### 3.8 WS2812 灯带接口

- 组成:1 个数据 GPIO + 5V 供电 + 对地;数据线上串 300~500Ω,灯带电源端 ≥100µF 电解。
- **坑**:WS2812 标称 5V 逻辑,3.3V 直驱**通常**可用但处于规格边缘(批次相关);
  稳妥做法加一级电平转换(74AHCT125 一类);灯多时电流大(每颗最大 ~60mA),5V 轨按灯数预算。

## 4. 布局(Placement)要点

先布局后布线,布局定生死:

1. **分区**:画一张"城市规划图"——RF(模组天线)一个角、电源(AXP2101+电感)一个区、
   音频(codec+功放+麦)一个区、高速(USB/摄像头)一个区。**RF 与音频离电源电感都要远**。
2. **模组天线伸出板边**(或板边净空),朝外壳外侧方向。
3. 退耦电容紧贴各芯片电源脚(距离 < 3mm),这不是玄学,是回路面积。
4. 麦克风开孔位置先与外壳设计对齐(见 enclosure.md),喇叭座/电池座放板边。
5. FPC 座(屏/摄像头)方向与整机装配方向一致——排线不要出现"拧麻花"。
6. 按键、USB-C、IPEX 座全部板边,和外壳开孔一一对应。

## 5. 布线(Routing)要点

| 主题 | 规则 |
|---|---|
| 层叠 | 推荐 **4 层板**:Top(信号+器件)/ L2(完整 GND)/ L3(电源)/ Bottom(信号)。比 2 层贵一点,但 RF、USB、QSPI 的参考平面问题一次解决,新手强烈建议 4 层 |
| 天线净空 | 模组天线投影区**所有层禁止铺铜、禁止走线、禁止打字丝印**,并按乐鑫硬件设计指南保留板边净空;外壳该区域无金属 |
| USB 差分 | D+/D- 按 90Ω 差分阻抗(立创 EDA 阻抗计算器按嘉立创层叠算)、等长(±0.7mm 内)、成对走、不跨地平面分割、少打孔 |
| QSPI | 同组短且大致等长(±5mm 工程经验),下方 L2 地平面完整 |
| I2S/MCLK | 短、不穿 RF 区、不与功放输出并行 |
| DCDC | 电感-输入电容-芯片的开关环路面积最小化;开关节点(SW)铜皮小而粗;**RF 与 DCDC 之间用完整地平面隔离,间距拉开** |
| 电源 | 3.3V 主干用粗线/铺铜(≥1mm 或整块铜皮),大电容分布在模组与功放附近 |
| 地 | L2 整层完整地,信号换层处就近打地过孔("缝合孔") |

## 6. DRC 与下单前检查

1. 立创 EDA:设计规则里导入/对照**嘉立创工艺参数**(经济型:最小线宽/线距 3.5mil、最小孔 0.2/0.3mm 等,以官网当前工艺页为准),然后跑 DRC 清零。
2. 人工 checklist(DRC 查不出来的):
   - [ ] 天线净空区干净(逐层看);
   - [ ] CC1/CC2 的 5.1k 在位;
   - [ ] strapping 引脚上没有外设输出;
   - [ ] GPIO35/36/37 没被使用;
   - [ ] FPC 座上/下接方向与屏、摄像头排线比划过;
   - [ ] 电池座极性丝印清晰;
   - [ ] BOOT/RESET/UART0 测试点在位;
   - [ ] 每颗 IC 的 I2C 地址不冲突(列表核对);
   - [ ] 丝印:版本号 + 日期 + 关键接口标注(未来的你会感谢现在的你)。
3. 最好找个懂硬件的朋友 review 原理图 30 分钟;没有就把工程发到立创开源广场/相关社群求拍砖——respin 一次的代价远大于面子。

## 7. 嘉立创下单(PCB + 经济型 SMT)

立创 EDA 内点"一键下单"自动生成 Gerber/BOM/坐标文件,流程:

1. **PCB 参数**:
   - 层数:4 层;板厚 1.6mm(装配无特殊要求就用它);
   - 数量:5 片起(经济型有优惠活动价);
   - 阻焊颜色随意(绿色最快),工艺默认(有铅喷锡/沉金按预算,USB-C 与 FPC 座建议沉金更好焊);
   - 费用量级:10×10cm 内 4 层 5 片,**几十元级**(活动价,估算)。
2. **经济型 SMT**(嘉立创贴片):
   - 只贴**单面**、器件在嘉立创贴片库内(基础库免上料费,扩展库每种收几十元上料费——选器件时就该注意,见 §2);
   - 屏、摄像头模组、GPS 模组、喇叭、电池、FPC 座若不在库,选择**不贴,自己手焊**(FPC 座 0.5mm 脚距手焊需要练习,备焊锡吸带;或加钱用样品定制贴片服务);
   - 费用量级:工程费 + 钢网 + 元件费 + 贴装费,一板 5 片总计 **约 ¥150~500(估算,强依赖 BOM)**。
3. 下单后 1~3 天审单,有问题客服会打电话(比如封装异常),配合修改即可;总周期约 1~2 周到手。

## 8. 回板调试 checklist(bring-up,严格按顺序)

> 原则:**电源 → 烧录 → 逐外设**,一次只引入一个变量。准备:万用表、镊子、(强烈建议)USB 电流表小尾巴;有条件借逻辑分析仪(¥100 级的够用)。

### 第 0 步:上电前目检
- [ ] 对着布局图检查芯片方向(1 脚点)、有无连锡/立碑/掉件;
- [ ] 万用表蜂鸣档测 **VBUS-GND、3V3-GND 不短路**(几百欧以上正常,蜂鸣长响=短路,先修再上电)。

### 第 1 步:电源轨
- [ ] 接 USB(此时不插电池),用电流表观察:静态电流应在几十 mA 内,若数百 mA 且芯片发烫立即断电;
- [ ] 万用表逐轨量电压:3.3V 主轨、屏轨、摄像头轨(若有)在标称 ±5% 内;
- [ ] 都正常后再单独验证电池路:电池经万用表确认极性(见 devboard.md §4.2)再插,验证充电。

### 第 2 步:烧录通道
- [ ] `idf.py flash` 一个 hello-world(或直接烧 PixelBox 固件,板型选 `BOARD_CUSTOM_V1`);
- [ ] 烧不进:按住 BOOT 上电重试 → 还不行走 UART0 后门(USB 转串口接 TXD0/RXD0)看 ROM 日志,
      日志会直言 strapping/Flash 问题;
- [ ] monitor 能看到启动日志 = 最小系统活了,**开香槟的第一个节点**。

### 第 3 步:逐外设点亮(每步固件 Kconfig 只开当前外设)
1. **I2C 扫描**:跑 I2C 扫描(固件调试命令或示例),应扫出触摸/IMU/PMU/RTC/codec 各地址——
   谁缺席查谁的电源与上拉;
2. **屏**:点亮纯色 → 不亮先量屏电源轨,花屏/偏移查 QSPI 接线与初始化序列(对照微雪参考);
3. **触摸**:读坐标,方向反了在固件板型里改映射;
4. **音频放**:`tone()` 出声 → 爆音查功放退耦,无声查 MCLK/I2S 接线与 ES8311 寄存器日志;
5. **音频录**:录一段回放(loopback),底噪大查麦布局/地;
6. **IMU**:读数据,静止时 az≈1g;
7. **摄像头**(若有):capture 一帧 JPEG → 全黑查 XCLK 与电源,花屏查 D0~D7 顺序;
8. **GPS**(若有):窗边收 NMEA 语句(先看 UART 有无输出,再谈定位);
9. **LED**(若有):fill 红绿蓝各一次,颜色错位是 GRB/RGB 顺序问题(固件配置改)。

### 第 4 步:整机联调
- [ ] 全外设同开跑语音对话 + 动画,观察电源稳定性(brownout 重启=电源余量不足);
- [ ] Wi-Fi RSSI 对比手机同位置,差距过大回查天线净空;
- [ ] 记录所有问题到 `docs/hardware/`(下一版改版清单)。
