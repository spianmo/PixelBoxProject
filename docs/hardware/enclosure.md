# 外壳落地指南(3D 打印)

> 目标读者:不会建模、没玩过 3D 打印的软件工程师。本章讲:内部堆叠尺寸怎么量、
> 建模的"免建模路线"和"自学路线"、打印工艺怎么选、结构细节(公差/卡扣/热熔螺母/透声孔)、
> 以及嘉立创三维猴与拓竹打印机两种下单/出件方式。
>
> 参考形态见 [product.md](../product.md) 渲染图与爆炸图(assets/exploded.png)。
> 所有价格为估算,以平台当日报价为准。

## 1. 先量尺寸链(建模前唯一必须做对的事)

外壳设计的本质是:**内部零件堆叠总高 + 间隙 = 内腔尺寸**。别急着开软件,先拿卡尺(数显卡尺 ~¥30,必买)把下面的表填满:

### 1.1 逐件测量表(示例结构,按实物填)

| 零件 | 量什么 | 记录 |
|---|---|---|
| 开发板 | 长 × 宽 × **最高点厚度**(注意:厚度要含背面最高的元件,如排线座/USB 座) | ___ |
| 屏幕区域 | 屏在板上的位置(距板边 x/y)、屏面高出板面多少 | ___ |
| 喇叭(含腔体) | 直径/长宽 × 厚,引线出线方向 | ___ |
| 电池 | 长 × 宽 × 厚(**再加 1mm 鼓包余量**) | ___ |
| USB-C 口 | 中心距板边缘的 x/z 偏移、口宽高 | ___ |
| 按键(BOOT/RESET) | 位置与顶面高度 | ___ |
| 麦克风开孔 | 板上麦孔位置(对外壳开孔) | ___ |
| 天线区 | 位置与范围(外壳此处禁金属,见 devboard.md §5) | ___ |

### 1.2 叠出内腔(画一张手绘截面图就够)

```
 ┌─ 前壳面板(壁厚 2.0)
 │  屏幕玻璃面      ── 与前壳开窗齐平或低 0.5
 │  开发板(含元件) ── 厚 a
 │  空气间隙        ── ≥1.5(走线/公差)
 │  喇叭腔体        ── 厚 b(出音面朝前壳/底壳透声孔)
 │  空气间隙        ── ≥1.0
 │  电池            ── 厚 c + 1 鼓包余量(泡棉双面胶固定)
 └─ 底壳(壁厚 2.0)
 内腔高度 = a+b+c + 间隙合计;外形高度 = 内腔 + 前后壁厚
```

规则:
- 每层零件之间**至少留 1~1.5mm 间隙**,排线经过的地方额外 +1mm;
- 壁厚 2.0mm(FDM)/1.5~2.0mm(树脂)起步,不要为了小而减到 1.2 以下;
- 螺柱、卡扣占的空间也要算进平面尺寸;
- 量完先用纸箱/亚克力垫片"干堆叠"一次验证总高,再开始建模。

## 2. 建模路线选择

### 路线 A:免建模(最快见到实物)

1. **找人代建模**:淘宝搜"3D 建模代画 外壳",提供:上面的尺寸表 + 实物多角度照片 +
   渲染图(assets/ 里的图直接发给对方当风格参考)+ 开孔清单(USB/按键/透声孔/麦孔)。
   价格量级 ¥100~500(估算,按复杂度),沟通 1~2 轮出 STL/STEP。**务必索要 STEP 源文件**,以后改尺寸不求人。
2. **参数化盒子生成器**:Printables/Thingiverse 搜 "parametric box / Ultimate Box Maker"(OpenSCAD,
   在网页 Customizer 里填长宽高/壁厚/螺柱就出 STL),再让打印店/朋友帮忙用切片软件挖 USB 口和屏窗。
   适合先做一个"能用的丑盒子"验证堆叠,再迭代好看的。
3. **社区现成外壳**:Printables 搜微雪板型号,可能已有人分享外壳,改改就能用(注意授权协议)。

### 路线 B:自学 Fusion 360(两小时上手,长期最划算)

Fusion 360 个人非商用许可免费(官网注册),对软件工程师非常友好(时间线=可回放的操作历史,约束=声明式)。

**两小时上手清单**(每项 B 站搜"Fusion 360 + 关键词"看一个 10 分钟视频即可):

| 顺序 | 技能 | 用在哪 |
|---|---|---|
| 1 | 草图(Sketch):矩形/圆/尺寸标注/约束 | 画外壳轮廓与开孔 |
| 2 | 拉伸(Extrude)与切除 | 长出盒身、挖 USB 口/屏窗 |
| 3 | 抽壳(Shell) | 实心块变盒子(壁厚 2.0) |
| 4 | 圆角(Fillet) | 渲染图那种圆润手感全靠它 |
| 5 | 分件:实体分割(Split Body) | 前壳/后壳拆开 |
| 6 | 螺柱/卡扣:凸台 + 孔 | 装配结构(见 §4) |
| 7 | 导出 STL(打印)/STEP(存档与代工) | 出件 |

练习项目就是这个外壳本身:先照 §1 的截面图建一个方盒 → 抽壳 → 开孔 → 分件,第一版丑没关系。

## 3. 打印工艺:FDM vs 光固化

| | FDM(熔融沉积,拓竹等) | 光固化(树脂,SLA/DLP) |
|---|---|---|
| 精度/公差 | ±0.2mm 量级,孔略缩 | ±0.1mm 量级,细节锐利 |
| 表面 | 有层纹(可接受/可打磨) | 接近注塑的光滑 |
| 强度 | 好(PETG/ABS 韧) | 标准树脂偏脆,卡扣易断(选韧性树脂) |
| 卡扣/热熔螺母 | 适合 | 卡扣需韧性树脂;热熔螺母可用 |
| 耐温 | PLA 60℃ 会软(盒内有电池发热,**别用 PLA 做长期件**,用 PETG/ABS) | 普通树脂 60~70℃,可选耐温树脂 |
| 成本 | 自有打印机极低;代打便宜 | 代打稍贵 |
| 结论 | **功能件/迭代首选** | **外观最终版首选** |

推荐节奏:FDM(PETG)快速迭代 2~3 版结构 → 尺寸锁定后光固化(韧性树脂)出外观版。

## 4. 结构细节设计

### 4.1 配合公差(±0.2 起步)

3D 打印不是 CNC,**孔会缩、轴会胖**:

- 插入配合(USB 口、按键孔、屏窗):开孔单边放大 **0.2mm**(FDM)/0.1mm(树脂);
- 零件间滑配:间隙 0.2~0.3mm;紧配(压入):0.05~0.1mm;
- 第一版打个"公差测试条"(一排 0.1/0.15/0.2/0.25/0.3 间隙的插槽)标定你的打印机/代打平台,以后都按它来;
- 屏窗与屏幕四周留 0.3~0.5mm,宁大勿刮屏。

### 4.2 前后壳连接:卡扣 + 热熔螺母

- **悬臂卡扣**(FDM/韧性树脂):臂厚 1.2mm、长 ≥8mm、钩深 0.8~1.0mm、钩面做 45° 导入斜角;
  打印方向让悬臂**沿层平面受力**(立着打的卡扣一掰就沿层断);
- **热熔螺母**(体验最好,强烈推荐):
  - 选 M2 铜热熔螺母(外径约 3.2~3.5mm,长 3~4mm,淘宝几分钱一颗);
  - 塑料柱孔径按螺母外径 −0.3mm(如外径 3.5 → 孔 3.2),柱外径 ≥ 孔径 +2.4(壁厚);
  - 安装:电烙铁 250℃ 顶着螺母垂直缓慢压入,平齐后移开等冷却;
  - 对面壳体用 M2×6 螺丝沉头孔;
- 建议:底壳 4 颗 M2 热熔螺母为主固定,卡扣只做辅助定位——可反复拆装,调试期尤其重要。

### 4.3 透声孔阵列(喇叭与麦克风)

- 喇叭出音面正对的壳面开孔阵:**孔径 1.0~1.2mm、间距 2.0~2.5mm(六角/圆形阵列)**,
  总开孔面积 ≥ 喇叭有效振膜面积的 15~20%,不然闷;
- 孔道长度=壁厚,此处壁厚可局部减到 1.5mm 让声音更透;
- 喇叭腔体出音面与壳内壁之间垫一圈 **1~2mm 泡棉密封圈**,防漏音与振动杂音;
- 麦克风:单孔 Ø1.0~1.5mm 正对板上麦孔,孔道尽量短,内侧同样泡棉圈密封——
  **麦孔与喇叭孔尽量分置不同壳面**(如麦在顶、喇叭在前/底),降低回声(barge-in 误触发);
- 防尘:孔阵内侧贴防尘网布(淘宝"喇叭防尘网布"背胶款)。

### 4.4 其他开孔与细节

- USB-C 口:开孔比座子单边大 0.3mm,并做外大内小的斜面导入,盲插不刮;
- 按键:直接开孔露出,或做"顶针"(外壳小柱按压传力),BOOT/RESET 至少留牙签孔;
- 底面贴硅胶脚垫(渲染图同款,淘宝背胶脚垫 Ø8mm);
- 天线区内壁不贴金属件、不走螺柱(见 devboard.md §5);
- 散热:底部/背部开几条缝或与透声孔阵合并(见 devboard.md §6)。

## 5. 出件:两条路

### 5.1 嘉立创三维猴(代打,无打印机)

1. 注册三维猴(嘉立创 3D 打印平台,与打板同账号体系);
2. 上传 STL → 选材料:
   - 迭代版:**尼龙(PA12,MJF/SLS)**——强度好、无支撑痕、公差稳定,或便宜的光固化 8228 树脂;
   - 外观版:高韧树脂 / 尼龙 + 手工喷漆;
3. 平台自动报价(按体积),小盒子两件套量级 **¥20~80/版(估算)**;
4. 检查平台提示的最小壁厚警告(<1.0mm 会被驳回或打断),下单,3~5 天到货。

### 5.2 拓竹(Bambu Lab)自有打印机

1. 切片软件 Bambu Studio 导入 STL;
2. 建议参数:PETG,层高 0.16~0.2mm,壁 3 圈,填充 15~25%,外壳面朝打印板放置(底面最光);
   卡扣件注意摆放方向(§4.2);
3. 打印,小盒子两件套约 2~4 小时,材料成本几块钱;
4. 迭代神器:改模型 → 重打 → 当天验证,结构调试期比代打快一个数量级。

## 6. 迭代 checklist

- [ ] v0:参数化丑盒子,只验证内腔与开孔位置(所有零件装得进、USB 插得上、按键按得到);
- [ ] v1:修公差,加卡扣/螺柱,验证拆装 10 次不坏;
- [ ] v2:透声孔阵 + 密封圈,实听音质与录音底噪;验证 Wi-Fi 信号(装壳前后 RSSI 对比);
- [ ] v3:圆角/外观/表面工艺,光固化或尼龙出最终版;
- [ ] 每版把改动记录在本目录(如 enclosure-changelog.md),尺寸链表随之更新。
